🗄️ Google Drive Database

सर्व नोंदी Google Drive मधील Spreadsheet मध्ये साठवल्या जातात. एकदा Script URL जोडला की सर्व data आपोआप sync होतो.

📋 Setup पायऱ्या:
  1. GoogleAppsScript_Backend.gs फाइल डाउनलोड करा
  2. Google Drive → New → Google Apps Script उघडा
  3. संपूर्ण code paste करा → Save करा
  4. Deploy → New Deployment → Web App निवडा
  5. Execute as: Me | Access: Anyone → Deploy
  6. Web App URL copy करा → येथे paste करा → जतन करा
